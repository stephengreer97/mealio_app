Three things the shape is hiding

The before-snapshot is load-bearing. If CART_COUNT phase=before never answers, there is no baseline, so there is no after-probe — and nothing in the run can contradict the workers. Every silent add defect reports success on its own checks; the cart diff is the only thing that has ever disagreed.

Reconcile trusts the cart, not the workers. A worker saying "added" is a claim. reconcileParallelAdd splits those claims three ways against a real cart read: confirmed, retry (re-added serially, unattended), and unverified — the count-item-on-a-weight-row case, which is neither re-added (that buys it twice) nor confirmed (that claims a delivery nobody checked).

A search failure ends as skipped, not failed. No exact match sends the item to the review screen, and the user's Skip there puts it in skippedNames. That is why manual mode offers failed and skipped — offering only the failed ones made the feature unreachable on the run that needed it.

What is unique to H-E-B

  • spaSearch: true — the search route re-renders and fires onLoadEnd a second time for the same URL. Without the flag the engine re-injects, spawning a duplicate SEARCH_AND_ADD_RESULT that over-advances the item index and silently skips an item.
  • nextDataSearch (off) — read results out of <script id="__NEXT_DATA__"> instead of scraping cards, which is where the sponsored and "perfect pairings" carousels simply are not present. Degrades back to the DOM extractor at runtime, so it can lose speed but not correctness.
  • cartSkuConfirm (off) — confirm each add against H-E-B's own cart query instead of the header badge. Every failure mode resolves to "we could not read the cart", never to "the item is missing".
  • networkAdd (off, requires cartSkuConfirm) — diagram 2.
  • Two login URLs. A logged-out profile click redirects to accounts.heb.com, an OIDC /authorize URL the generic auth-redirect skip would swallow, so H-E-B declares its own isLoginPageUrl and re-injects the login check when the chain settles back on the store.
